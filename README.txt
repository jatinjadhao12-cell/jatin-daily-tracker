JATIN Daily Tracker — Web app

Files:
- index.html: complete tracker
- manifest.webmanifest: installable web app settings
- sw.js: offline cache

Quick start:
1. Extract this ZIP.
2. Open index.html in a browser for basic use.
3. To install it as a home-screen app and enable offline caching, serve/host this folder on HTTPS (for example, GitHub Pages), open it in Chrome, then choose Install app / Add to Home screen.

Features:
- Dark theme and your timetable
- Daily checkboxes and daily/weekly progress reports
- Current and best streaks (a day counts at 80% completion)
- Achievement badges and previous-day history
- Edit/add/remove timetable tasks
- JSON backup export/import
- Local browser storage; no account needed

Start date: 16 November 2026.
The app starts on today's date on/after the start date. Earlier days can be selected in the date picker.

Data note: Data stays in this browser on this device. Export a backup before clearing browser data or changing devices. This version does not sync between devices.
